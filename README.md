# useful-bits

A collection of reusables (utilities, components, and snippets) I’ve built
and tend to use across various projects. 

### Contents
- React components & hooks
- TypeScript utilities & patterns
- WordPress functions & snippets
- Miscellaneous helpers

### Usage
Each folder is self-contained. Copy what you need.
Some utilities may require small adjustments per project.

### Note
I use shadcn/ui and tailwind for components so keep that in mind.
